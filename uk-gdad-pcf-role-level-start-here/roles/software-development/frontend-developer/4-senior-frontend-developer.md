# Senior frontend developer - start here

Welcome. If you are working toward the senior frontend developer level, this
page is for you: what the role expects, where to find everything else this
repository has for it, and a pathway for building the skills it asks for.

## Purpose

A senior frontend developer is an experienced developer who works with
minimal support and can influence and mentor others. You're expected to help
set direction and embed good practice within teams, make decisions based on
research rather than instinct alone, plan and lead development on sets of
related stories while working with other disciplines to understand what
needs building, hold an understanding of the whole system rather than just
your part of it, and teach and mentor others as a routine part of the job.
Several skills sharpen noticeably at this level — strategic thinking,
systems integration, web performance — because owning a piece of work
end to end asks more of you than delivering it well once did.

## Learning pathway

Work through these roughly in order. Each one is a requirement of this role
level. At this level, an AI tool is often most useful for pressure-testing a
design or architecture decision — describe the actual trade-off you're
weighing and ask what you might be missing.

- [ ] **Own integration end to end, not just contribute to it**

  Define the static assets build, co-ordinate all aspects of the
  integration, take responsibility for the tests around the user interface,
  and configure and test the part of the system that uses the network.

  Ask AI: "What does taking full responsibility for integration testing
  look like, compared with contributing to it as part of a wider team?"

- [ ] **Shape strategy, not just work within it**

  Define strategies and policies, providing guidance to others on working
  in the strategic context, and evaluate current strategies to check
  business requirements are being met and exceeded where possible.

  Ask AI: "How would a senior developer evaluate whether an existing
  strategy is actually still meeting business requirements, rather than
  assuming it still is?"

- [ ] **Deepen how you represent users internally**

  Collaborate with user researchers and interaction designers to represent
  user needs internally, explain the difference between user needs and
  user desires, champion user research so it covers all users, and guide
  others in understanding the user story.

  Ask AI: "What's the practical difference between what users need and
  what users say they want, and how would a senior developer explain that
  difference to a colleague who's confusing the two?"

- [ ] **Take ownership of resolving performance issues**

  Identify and resolve web performance issues, collect data to monitor and
  resolve them, and guide others on the best web performance optimisation
  approaches and methods to use.

  Ask AI: "What data would a senior developer collect to genuinely
  understand a web performance problem, rather than guessing at the cause?"

- [ ] **Make and recommend risk-based decisions, and shape best practice**

  Make decisions characterised by medium levels of risk and complexity,
  recommend decisions as risk and complexity increase further, and
  contribute to the team's best practice guidelines.

  Ask AI: "How should a senior developer decide when a decision is risky
  enough that it needs a recommendation to someone else, rather than making
  the call alone?"

- [ ] **Keep championing accessibility**

  This skill's wording plateaus here, unchanged from the level below:
  building user interfaces to a predefined standard, championing
  accessibility to internal stakeholders, and offering design feedback and
  tool recommendations for accessibility testing.

  Ask AI: "Given this skill's description hasn't changed since the level
  below, what would genuinely senior-level accessibility practice add
  beyond what's written here?"

- [ ] **Keep managing stakeholder communication**

  This skill's wording also plateaus here: working collaboratively,
  identifying issues through team health checks, managing stakeholder
  expectations, and hosting or moderating difficult discussions.

  Ask AI: "What would managing stakeholder communication at a genuinely
  senior level look like, beyond what's described in this skill?"

- [ ] **Keep shaping team dynamics**

  This skill plateaus too: networking within the team, adapting feedback so
  it lasts, and using team health checks to spot and address issues.

  Ask AI: "What role should a senior developer, as distinct from a formal
  team lead, play in shaping team dynamics?"

- [ ] **Keep applying development standards, and supporting others**

  This skill's wording is unchanged from the level below: applying modern
  development standards and supporting others in applying them.

  Ask AI: "What separates genuinely strong support for a colleague applying
  a development standard from just correcting their code?"

- [ ] **Keep building interfaces of real complexity**

  This skill also plateaus: collaborating on specifications, then building,
  testing and documenting user interfaces of medium to high complexity to
  the right standards.

  Ask AI: "What's the difference between building an interface competently
  and building it the way a genuinely senior developer would?"

- [ ] **Keep treating prototyping as a team activity**

  This skill plateaus as well: approaching prototyping as a team activity,
  establishing and iterating design patterns, and choosing the right method
  from several available.

  Ask AI: "What might a senior developer do differently in a prototyping
  session compared with a more junior one, even if the described skill
  looks the same on paper?"

Ask your manager or a lead colleague which of these matters most in your
organisation right now, and start there.
