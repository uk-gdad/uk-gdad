# Senior data engineer - start here

Welcome. If you are working toward the senior data engineer level, this
page is for you: what the role expects, where to find everything else this
repository has for it, and a pathway for building the skills it asks for.

## Purpose

A senior data engineer designs and leads implementing the data flows that
connect operational systems to analytics and business intelligence systems.
You recognise opportunities to reuse existing flows rather than building
new ones from scratch, lead building data streaming systems, optimise code
so processes perform well, and lead work on database management. Most named
skills grow at this level, because you're now designing and leading rather
than delivering someone else's design.

## Learning pathway

Work through these roughly in order. Each one is a requirement of this role
level. Where you want to go deeper, ask an AI tool a specific question
rather than searching for a generic guide — you'll get an answer shaped
around your own data flows.

- [ ] **Design and build programs of real complexity**

  Use agreed standards and tools to design, code, test, correct and
  document moderate-to-complex programs and scripts from agreed
  specifications, collaborating with others to review specifications
  where appropriate.

  Ask AI: "What changes about reviewing a specification once you're
  building moderate-to-complex programs, rather than simple ones under
  direction?"

- [ ] **Design and lead building complex data products**

  Design, build and test data products that are complex or large scale,
  and build teams to complete data integration services rather than
  delivering them alone.

  Ask AI: "What changes about building a data product once its scale or
  complexity means you need a team to complete it, rather than one
  engineer?"

- [ ] **Select the right technologies for resilient data solutions**

  Select and implement the appropriate technologies to deliver resilient,
  scalable and future-proofed data solutions, rather than following
  someone else's technology choice.

  Ask AI: "How would a senior data engineer compare technology options for
  a resilient data solution, beyond picking the one they're most familiar
  with?"

- [ ] **Produce and compare data models across subject areas**

  Produce relevant data models across multiple subject areas, explain
  which models suit which purpose, understand industry-recognised
  modelling patterns and standards and when to apply them, and compare and
  align different data models.

  Ask AI: "How would a senior data engineer decide whether two data
  models from different subject areas can be aligned, or should genuinely
  stay separate?"

- [ ] **Design and improve metadata repositories**

  Design an appropriate metadata repository, suggest improvements to
  existing ones, understand a range of tools for storing and working with
  metadata, and advise less experienced team members.

  Ask AI: "What would tell a senior data engineer that an existing
  metadata repository needs redesigning, rather than incremental
  improvement?"

- [ ] **Investigate patterns behind problems, and consult specialists**

  Initiate and monitor actions to investigate patterns and trends behind
  problems, consult specialists where needed, determine the right
  resolution and help implement it, and identify preventative measures.

  Ask AI: "What's the difference between fixing a data problem and
  preventing the same class of problem from recurring, and how would a
  senior data engineer approach the second?"

- [ ] **Understand the organisational impact of emerging data trends**

  Understand the impact on the organisation of emerging trends in data
  tools, analysis techniques and data usage — a step up from simply being
  aware of them.

  Ask AI: "How would a senior data engineer judge whether an emerging data
  trend is genuinely relevant to their organisation, rather than
  interesting in the abstract?"

- [ ] **Handle harder conversations across a multidisciplinary team**

  Communicate effectively with technical and non-technical stakeholders,
  support discussions within a multidisciplinary team that may have
  difficult dynamics, advocate for your team externally, and manage
  differing stakeholder perspectives.

  Ask AI: "What should a senior data engineer focus on when explaining a
  technical data pipeline decision to a non-technical stakeholder, so it
  actually lands?"

- [ ] **Keep profiling data and presenting clear insight**

  This skill's wording plateaus here, unchanged from data engineer level:
  undertaking data profiling and source system analysis, and presenting
  clear insight to support how data gets used.

  Ask AI: "Given this skill's description hasn't changed since the level
  below, what would genuinely senior-level analysis judgement add beyond
  what's written here?"

- [ ] **Keep defining test conditions, and analysing results**

  This skill also plateaus: reviewing requirements to define test
  conditions, identifying issues and risks, and analysing test results.

  Ask AI: "What would leading testing practice across a team add, beyond
  defining and analysing test conditions well yourself?"

Ask your manager or a more senior colleague which of these your team relies on
most right now, and start there.
