# Senior machine learning engineer - start here

Welcome. If you are working toward the senior machine learning engineer
level, this page is for you: what the role is about, where to find
everything else this repository has for it, and a pathway for building the
skills it asks for. The framework publishes this as the first of only two
levels for this role, and it already reads at a genuinely experienced
register — this is not a role most people arrive at as their first job in
data.

## Purpose

A machine learning engineer develops, assures and maintains machine
learning models so they can be used in real products and services — taking
responsibility for the software development and infrastructure needed to
design, train, deploy and scale them, keeping them effective, secure and
sustainable, supporting every stage of the machine learning life cycle, and
helping product teams evaluate and choose the right solutions. At this
level, you decide which model genuinely suits a product or service,
customise, optimise, retrain and maintain existing models, deploy them into
production while testing and assuring they meet performance requirements,
work with others to integrate them with existing systems, and check that
live models stay safe, secure and effective over time.

## Learning pathway

Work through these roughly in order. Each one is a requirement of this role
level, described plainly, with a way to go deeper by asking an AI tool a
specific question — the answers you get will be shaped around your own
models and systems, which a generic guide never is.

- [ ] **Design and build to agreed specifications**

  Collaborate with others when necessary to review specifications, then
  use the agreed specifications to design, code, test and document
  programs of medium-to-high complexity, using the right standards and
  tools.

  Ask AI: "What changes about reviewing a specification for a machine
  learning system, compared with reviewing one for a typical software
  feature?"

- [ ] **Coordinate integration across systems**

  Define the integration build, co-ordinate build activities across
  systems, and understand how to support integration testing across the
  whole effort rather than one interface at a time.

  Ask AI: "What does integrating a machine learning model into an
  existing system actually involve, beyond deploying the model itself?"

- [ ] **Apply quantitative techniques to build and embed models**

  Apply designated quantitative techniques such as time series analysis,
  optimisation and simulation to create and embed models for analysis and
  prediction, guide others on matching data sources to techniques, and use
  the statistical tools available in your organisation.

  Ask AI: "How would a senior machine learning engineer decide whether
  time series analysis, optimisation or simulation fits a given
  prediction problem?"

- [ ] **Demonstrate practical knowledge, and spot opportunities to improve**

  Demonstrate practical knowledge of data science tools and techniques,
  develop solutions that maximise insight, and identify opportunities for
  data science to improve data practices.

  Ask AI: "What's a good way for a machine learning engineer to identify
  where an existing model or pipeline could be meaningfully improved?"

- [ ] **Handle harder conversations with senior stakeholders**

  Listen to and interpret the needs of technical and non-technical
  stakeholders, manage active and reactive communication, and support or
  host difficult discussions with the team or with diverse senior
  stakeholders.

  Ask AI: "How would a senior machine learning engineer explain a model's
  limitations to a senior stakeholder who wants a simple yes-or-no answer
  about whether it's ready?"

- [ ] **Address ethical and privacy concerns, and challenge policy**

  Work with stakeholders to identify and address ethical and privacy
  concerns, communicate how ethical issues fit into the wider
  organisational context, research developments in data ethics, and
  constructively challenge proposed data ethics policies.

  Ask AI: "What's an example of an ethical concern specific to machine
  learning models, such as bias in training data, and how would an
  engineer raise it constructively?"

Ask a lead machine learning engineer, or an equivalent senior colleague,
which of these matters most in your organisation right now, and start
there.
