# UK GDAD PCF assessments (by assessor)

An assessor-administered psychometric assessment for every role level in the
United Kingdom Government Digital and Data (GDAD) Profession Capability
Framework (PCF).

**205 documents**, one per role level, each written from that level's
[role summary](../uk-gdad-pcf-role-summaries).

> **This is not a validated assessment instrument.** It has not been piloted,
> normed, or checked for adverse impact, and a result from it must never be the
> sole basis for a hiring, promotion, pay, performance or disciplinary
> decision. Every document repeats this in its Advisory section.

## Who this is for

A manager, panel, or reviewer administering a structured, job-specific
assessment to a candidate — not the candidate's own practice material. Every
item's worked answer is the assessor's answer key, held back until scoring.
Looking for the candidate's own practice material instead? See
[`uk-gdad-pcf-psychometric-assessments-by-yourself`](../uk-gdad-pcf-psychometric-assessments-by-yourself),
the same four assessment types rewritten for the reader to work through
alone. See
[`uk-gdad-pcf-competency-assessments-by-assessor`](../uk-gdad-pcf-competency-assessments-by-assessor)
for the companion instrument that measures demonstrated skill against a
baseline rather than reasoning through items.

## Why job-specific

Employers increasingly use *workplace job-specific* assessments — tied to the
actual skills and duties of a role — rather than generic aptitude tests. These
documents follow that approach: scenarios come from the accountabilities the
framework lists for the level, so the practice is about the job.

## What a document contains

| Section | What it holds |
| --- | --- |
| Introduction | What this is and how to use it |
| Advisory | The standing caution |
| Workplace job-specific cognitive assessment | Inference and problem solving in the role's domain |
| Workplace job-specific numeric reasoning assessment | The numbers this role handles |
| Workplace job-specific verbal reasoning assessment | The documents this role reads |
| Workplace job-specific situational judgement assessment | Scenarios from the role's accountabilities |
| Conclusion | What to do next |

Every practice item comes with a worked answer and an explanation.


Or read it on the web: <https://uk-gdad.github.io/assessments-by-assessor/>

run to tens of thousands of words, so the website is usually the easier way in.
