# Skills — the framework catalogue

A snapshot of the skill names the framework publishes, and how this
repository's two skill vocabularies compare against it. Referenced by
[`spec/index.md` § Known drift](index.md#known-drift).

**Source:** <https://ddat-capability-framework.service.gov.uk/skills>
**Fetched:** 2026-08-23 — 185 skills.

Re-fetch and re-compare when the framework changes upstream. This file is a
record, not an authority: the framework page is the authority.

## The three lists

| List | Where | Count |
| --- | --- | ---: |
| Official catalogue | The framework's Skills A to Z | 185 |
| Role summaries | `Skill:` lines across the 205 summaries | 183 |
| Self-assessment tool | The `inputs` list in `index.html` | 189 |

The counts differ for reasons that are not all defects:

- The catalogue lists every skill the framework publishes. A summary only names
  the skills its own role level requires, so the catalogue is naturally larger
  than the set any 205 levels happen to use between them.
- The tool rates a person against a skill catalogue, so it tracks the catalogue
  rather than the role levels.

## Named here but not in the catalogue (5)

All five appear in the self-assessment tool as well, so they are not a
transcription slip in one place — they look like a content-design vocabulary the
framework has since reorganised. Four are the same skill qualified for content
design. The catalogue now carries `User-centred content design` and
`Content management and architecture`, which may be where some of them went.

Mapping them needs the framework's content designer role pages, not a guess.

| --- | --- |
| `Agile working (content design)` | yes |
| `Content concepts and prototyping` | yes |
| `Stakeholder relationship management (content design)` | yes |
| `Strategic thinking (content design)` | yes |
| `User focus (content design)` | yes |
