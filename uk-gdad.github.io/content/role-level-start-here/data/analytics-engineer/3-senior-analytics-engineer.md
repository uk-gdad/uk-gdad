# Senior analytics engineer - start here

Welcome. If you are working toward the senior analytics engineer level,
this page is for you: what the role expects, where to find everything else
this repository has for it, and a pathway for building the skills it asks
for.

## Purpose

A senior analytics engineer oversees the development and testing of data
models, including directing the work of other analytics engineers. You
oversee tasks and support less senior colleagues, build relationships with
stakeholders within a defined area, coach and mentor others, make sure
documentation meets standards and issues and risks get resolved, oversee
training and support for data users, and explore new ways of working with
data. Most named skills grow at this level, because you're now accountable
for other people's models and models of real complexity, not just your own
simple ones.

## Learning pathway

Work through these roughly in order. Each one is a requirement of this role
level. At this level, an AI tool is often most useful for pressure-testing a
modelling or standards decision — describe the actual trade-off and ask
what you might be missing.

- [ ] **Build and review complex data models, and improve standards**

  Build and review complex data models, ensuring adherence to standards,
  use data integration tools and languages to integrate and store data,
  make sure data meets quality standards and is interoperable, and work
  with other data professionals to improve modelling and integration
  patterns.

  Ask AI: "How would a senior analytics engineer decide whether a data
  model is genuinely interoperable with other datasets, rather than just
  internally consistent?"

- [ ] **Design and improve metadata repositories**

  Design an appropriate metadata repository, suggest improvements to
  existing ones, understand a range of tools for storing and working with
  metadata, and advise less experienced team members.

  Ask AI: "What would tell a senior analytics engineer that an existing
  metadata repository needs redesigning, rather than incremental
  improvement?"

- [ ] **Investigate patterns behind problems, and consult specialists**

  Initiate and monitor actions to investigate patterns and trends behind
  problems, consult specialists where needed, determine the right
  resolution and help implement it, and identify preventative measures.

  Ask AI: "What's the difference between fixing a data problem and
  preventing the same class of problem from recurring, and how would a
  senior analytics engineer approach the second?"

- [ ] **Design and build programs of real complexity**

  Use agreed standards and tools to design, code, test, correct and
  document moderate-to-complex programs and scripts from agreed
  specifications, collaborating with others to review specifications where
  appropriate.

  Ask AI: "What changes about reviewing a specification once you're
  building moderate-to-complex programs, rather than simple ones under
  direction?"

- [ ] **Define test conditions, and analyse results**

  Review requirements and specifications to define test conditions,
  identify issues and risks associated with the work, and analyse and
  report on test activities and results.

  Ask AI: "What makes a test condition genuinely well-defined, as opposed
  to a vague check that something 'looks right'?"

- [ ] **Understand the organisational impact of emerging data trends**

  Understand the impact on the organisation of emerging trends in data
  tools, analysis techniques and data usage — a step up from simply being
  aware of them.

  Ask AI: "How would a senior analytics engineer judge whether an emerging
  data trend is genuinely relevant to their organisation, rather than
  interesting in the abstract?"

- [ ] **Keep communicating across a multidisciplinary team**

  This skill's wording plateaus here, unchanged from analytics engineer
  level: communicating effectively with stakeholders, supporting
  discussions in a team with difficult dynamics, and advocating for your
  team externally.

  Ask AI: "Given this skill's description hasn't changed since the level
  below, what would genuinely senior-level communication judgement add
  beyond what's written here?"

- [ ] **Keep profiling data and presenting clear insight**

  This skill also plateaus: undertaking data profiling and source system
  analysis, and presenting clear insight to support how data gets used.

  Ask AI: "What would leading data analysis across a defined area add,
  beyond profiling data and presenting insight well yourself?"

Ask a lead analytics engineer, or an equivalent principal colleague, which
of these matters most in your organisation right now, and start there.
