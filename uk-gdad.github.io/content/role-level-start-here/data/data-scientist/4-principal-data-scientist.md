# Principal data scientist - start here

Welcome. If you are working toward the principal data scientist level,
this page is for you: what the role expects, where to find everything else
this repository has for it, and a pathway for building the skills it asks
for.

## Purpose

A principal data scientist is a leader of data science, quite often with
responsibility for managing and developing teams. You have broad knowledge
of data science techniques, use cases and potential impact, extensive
experience scoping, designing and delivering data science outputs, work
collaboratively with a range of experts in support of organisational
objectives, communicate effectively and challenge delivery plans and
priorities, and appreciate data ethics, data preparation, delivery methods
and how to deliver supported solutions at scale. Applied maths, data
engineering, data science innovation, delivering business impact and
programming all sharpen at this level, because you're now setting direction
and supervising others, not just producing your own output.

## Learning pathway

Work through these roughly in order. At this level, an AI tool is often
most useful for pressure-testing a technical or team decision — describe
the actual trade-off and ask what you might be missing.

- [ ] **Write complex programs, and set coding standards for your team**

  Write complex programs and scripts, make code open source where
  appropriate, supervise junior analysts and set coding standards, and
  understand software architecture well enough to write efficient code
  and perform user testing before launch.

  Ask AI: "What makes a coding standard something a team actually
  follows, rather than a document set once and never revisited?"

- [ ] **Use advanced techniques through the whole data life cycle**

  Identify opportunities to develop statistical insight and models that
  support organisational objectives, critique statistical analyses, use
  techniques such as data mining and predictive analytics through the
  whole data life cycle, use model outputs to help design services and
  policies, and help others use the tools available.

  Ask AI: "How would a principal data scientist decide which advanced
  technique genuinely fits a business problem, rather than the most
  sophisticated one available?"

- [ ] **Identify data engineering requirements, and help others use tools well**

  Help identify data engineering requirements for a data science product
  while working with data engineers to design and deliver it effectively,
  understand the need for reusable cleansing processes, and understand a
  broad range of architectures and tools well enough to help others use
  them.

  Ask AI: "What does a principal data scientist need to understand about
  data engineering to collaborate well with engineers, without doing their
  job for them?"

- [ ] **Lead data science innovation, and coach others in curiosity**

  Be a leader in the data science space, demonstrate in-depth knowledge to
  solve problems creatively and create opportunities for your team, act as
  a coach inspiring curiosity and creativity in others, keep up to date
  with the industry, and challenge the status quo.

  Ask AI: "What does 'coaching curiosity' in a data science team actually
  look like, as distinct from just assigning interesting problems?"

- [ ] **Lead using data science to create organisational change**

  Lead and support your organisation area by using data science to create
  change, identify opportunities to develop products supporting
  organisational objectives, understand the role of user research,
  communicate compelling stories with clear visualisations, and work with
  colleagues to implement scalable products and understand maintenance
  needs.

  Ask AI: "How would a principal data scientist make the case that a data
  science initiative should drive organisational change, to stakeholders
  who see it as a technical exercise?"

- [ ] **Keep addressing ethical and privacy concerns**

  This skill's wording plateaus here, unchanged from data scientist level:
  working with stakeholders on ethical and privacy concerns, researching
  developments, and constructively challenging proposed policies.

  Ask AI: "Given this skill's description hasn't changed since the level
  below, what would genuinely principal-level data ethics judgement add
  beyond what's written here?"

- [ ] **Keep supporting capability building across the team**

  This skill also plateaus: managing your own development, supporting
  capability building across the team, and demonstrating understanding of
  a range of techniques.

  Ask AI: "What would leading capability building for the whole
  organisation add, beyond supporting it well for one team?"

- [ ] **Keep choosing delivery methods, and defining the minimum viable product**

  This skill's wording plateaus too: understanding delivery method
  differences, defining the minimum viable product, and working with
  specialists to deliver smoothly.

  Ask AI: "What would leading delivery method decisions across several
  products add, beyond choosing well for one?"

Ask a lead data scientist, or an equivalent head-of-role colleague, which
of these matters most in your organisation right now, and start there.
