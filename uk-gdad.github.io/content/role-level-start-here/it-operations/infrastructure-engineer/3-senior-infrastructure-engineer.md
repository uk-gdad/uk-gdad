# Senior infrastructure engineer - start here

Welcome. If you are working toward the senior infrastructure engineer
level, this page is for you: what the role expects, where to find
everything else this repository has for it, and a pathway for building the
areas it names.

## Purpose

Working in a team of infrastructure specialists and engineers, a senior
infrastructure engineer designs and implements solutions as directed and
according to departmental policy, working with technical architects to
translate architectural designs into operations and, on a managerial path,
leading infrastructure specialist teams. Most named skills grow at this
level, because designing and implementing infrastructure asks for more than
building and configuring it under direction.

## Learning pathway

Work through these roughly in order. Where you want to go deeper, ask an AI
tool a specific question rather than searching for a generic guide — you'll
get an answer shaped around your own organisation's infrastructure.

- [ ] **Design and implement infrastructure solutions**

  Design and implement infrastructure solutions and services — for
  example, networking and physical infrastructure, commercial-off-the-shelf
  software, open source packages and solutions, or virtual and cloud
  computing.

  Ask AI: "What's the difference between building infrastructure someone
  else designed and designing it yourself, in terms of the decisions you're
  now responsible for?"

- [ ] **Design systems with medium risk and complexity**

  Design systems characterised by medium levels of risk, impact, and
  business or technical complexity, select appropriate design standards,
  methods and tools, and review the designs of others.

  Ask AI: "What should a senior infrastructure engineer look for when
  reviewing a colleague's system design, beyond whether it technically
  works?"

- [ ] **Define the integration build, and co-ordinate it**

  Define the integration build, co-ordinate build activities across
  systems, and understand how to undertake and support integration
  testing activities.

  Ask AI: "What does 'defining the integration build' involve, that
  building and testing a single interface doesn't?"

- [ ] **Review requirements, and analyse test results**

  Review requirements and specifications to define test conditions,
  identify issues and risks associated with the work, and analyse and
  report on test activities and results.

  Ask AI: "What makes a test condition genuinely well-defined, as opposed
  to a vague check that something 'looks right'?"

- [ ] **Use information security practices to protect services**

  Use information security practices and available security controls to
  contribute to protecting solutions and services.

  Ask AI: "What's the difference between explaining security controls and
  actively using them to protect a live service?"

- [ ] **Apply modern development standards, and support others**

  Apply modern development standards, and support others in applying
  them.

  Ask AI: "What does supporting a colleague in applying modern development
  standards look like, beyond applying them well yourself?"

- [ ] **Break problems down to find their root cause**

  Troubleshoot and identify problems across different technology
  capabilities, breaking a problem down into its component parts to
  identify and diagnose root causes.

  Ask AI: "What's a structured way to break a complex infrastructure
  problem into component parts, rather than treating it as one big
  unknown?"

- [ ] **Keep owning an issue until it's genuinely resolved**

  This skill's wording plateaus here, unchanged from the level below:
  owning an issue until a new owner has been found or it's mitigated or
  resolved.

  Ask AI: "What would taking accountability for an issue, rather than just
  owning it until resolved, look like at the next level?"

- [ ] **Keep investigating patterns behind problems**

  This skill also plateaus: initiating and monitoring actions to
  investigate patterns and trends, consulting specialists, determining the
  right resolution, and identifying preventative measures.

  Ask AI: "What would leading problem management strategy across
  infrastructure add, beyond investigating patterns well yourself?"

- [ ] **Keep building coherent frameworks from scattered inputs**

  This skill's wording plateaus too: taking inputs and establishing
  coherent frameworks that work.

  Ask AI: "What would setting the standard for how frameworks get built
  across a team add, beyond building good ones yourself?"

- [ ] **Keep learning about scripting tools and software**

  This skill also plateaus: describing different scripting tools and
  software that are available and currently in use.

  Ask AI: "At what point does describing available scripting tools turn
  into choosing which ones a team should standardise on?"

Ask a lead infrastructure engineer which of these matters most in your
organisation right now, and start there.
