# Senior end user computing engineer - skills gap form

## Introduction

This form is for you if you work as a senior end user computing engineer in the UK Government Digital and
Data profession. Human resources or your manager has sent it so that you can set out what you do now, where
the gaps are, and what would close them.

The framework describes this level as responsible for managing the team while also getting involved in
solving technical problems. It expects you to manage, co-ordinate and prioritise tasks to resolve technical
incidents as quickly as possible, and to work closely with infrastructure, capacity managers and
availability managers to fix technical problems and **identify and escalate repeat issues** to the lead
engineer, the incident or problem manager and software developers.

Managing a team and staying technical at the same time is the standing tension of this level. Both are in
the job description, and the day rarely leaves room for both.

Eleven skills. Expect about 35 minutes.

## About this role level

**The role: end user computing engineer.** You manage the product life cycle of all service-raised incidents
and all service requests, using knowledge management, inform customers of progress, advise on workarounds,
and support and maintain end user services.

**Your level: senior end user computing engineer.** You are responsible for managing the team but also get
involved in solving technical problems. The framework expects that you:

- manage, co-ordinate and prioritise tasks to resolve technical incidents as quickly as possible
- work closely with infrastructure, capacity managers and availability managers to fix technical problems,
  and identify and escalate repeat issues to the lead end user computing engineer, the incident or problem
  manager and software developers

**Where this level sits.** This role has five levels:

1. Associate end user computing engineer
2. End user computing engineer
3. **Senior end user computing engineer** — you are here
4. Lead end user computing engineer
5. Principal end user computing engineer

Your next step is lead end user computing engineer: expert technical understanding, accountable for vendor
and supplier management, working with IT operations and other functions such as technical architecture.

**One thing worth knowing about this role.** Five of your eleven skills are worded **identically at end user
computing engineer** below you — asset and configuration management, ownership and initiative, service
focus, service management framework knowledge, and user focus. Six rose: change management, IT service
reporting, incident management, problem management, technical specialism and testing. That is a clear list
of where the step actually happened.

**The eleven skills this form covers**, in the framework's order:

1. Asset and configuration management

3. IT service reporting
4. Incident management

### Skill: Change management

**What the framework expects at this level.** Three things: **analyse and assess the impact of change**;

knowing which teams use which applications, who is travelling, and what happens if a rollout catches
someone mid-task.

procedures and processes are applied.

### Skill: User focus

function will ever gather. Turning that into something anyone acts on is the gap.
