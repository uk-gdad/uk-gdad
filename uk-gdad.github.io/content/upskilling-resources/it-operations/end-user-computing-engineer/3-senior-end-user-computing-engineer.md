# Senior end user computing engineer - upskill resources

This page focuses on learning and growth resources for the work role of senior end user computing engineer.

- The resources include links to online courses, blogs, research articles, videos, and books.

- These help with job upskilling, work training, professional development, and career advancement.

- These are intended to be good starting points, not a comprehensive catalogue.

At this role level you manage the team while still solving technical problems. You co-ordinate and prioritise work to resolve incidents quickly, work closely with infrastructure, capacity and availability colleagues, and escalate repeat issues rather than absorbing them. The resources below emphasise prioritisation, reporting that stakeholders can act on, change impact assessment, and the team leadership that comes with the level.

## Professional development tips

- Prioritise by user impact and by whether the fix prevents recurrence, not only by ticket age
- Escalate repeat issues with evidence attached, since a pattern with data gets acted on and a complaint does not
- Interpret your data set before presenting it, and say what you think it means
- Agree reporting changes with the people who read the reports, rather than changing format unilaterally
- Build working relationships with infrastructure, capacity, and availability colleagues before an incident forces one
- Protect your team's time for knowledge work, because it is the first thing squeezed and the highest leverage
- Stay hands-on enough to know whether a proposed fix is realistic
