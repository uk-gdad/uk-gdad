# Configuration analyst - upskill resources

This page focuses on learning and growth resources for the work role of configuration analyst.

- The resources include links to online courses, blogs, research articles, videos, and books.

- These help with job upskilling, work training, professional development, and career advancement.

- These are intended to be good starting points, not a comprehensive catalogue.

At this role level you provide administrative support to the change and release manager, help maintain the integrity of the configuration management database, and independently solve smaller problems. The resources below emphasise asset and configuration accuracy, applying change control under supervision, and the continuity and capacity concepts you need to be able to explain.

We welcome constructive feedback to improve this page and these lists.

- GitHub issues and/or pull requests are welcome.

- The resources are found via AI searches then go through human-in-the-loop proofing.

## Coursera courses

- [ITSM Foundations: Optimizing IT Service Management](https://www.coursera.org/learn/itsm-foundations-optimizing-it-service-management): Core ITSM principles through the ServiceNow platform, including how requests, incidents and problems are handled. No prior experience assumed.

- [Advanced ITSM with ServiceNow: Optimizing IT Operations](https://www.coursera.org/learn/advanced-itsm-with-servicenow-optimizing-it-operations): Covers change management and the configuration management database directly, which is the core of this role.

- [Technical Support Fundamentals](https://www.coursera.org/learn/technical-support-fundamentals): Hardware, networks, operating systems and troubleshooting. Useful if you need to understand what the configuration items in your database actually are.

## Udemy courses

- [ServiceNow Kickstart: Basic Skills for CMDB Administration](https://www.udemy.com/course/servicenow-kickstart/): Aligned to ServiceNow administration with a focus on configuring the CMDB. The most directly relevant course for this role level.

- [CMDB Done Right with ServiceNow](https://www.udemy.com/course/cmdb-done-right-with-servicenow/): Covers the service asset and configuration management process end to end: planning, design, run and audit, data sources, baselines, configuration item relationships and reporting.

- [Change Management (ITSM ServiceNow)](https://www.udemy.com/course/change-management-itsm-servicenow/): Change management in practice, including the communication needed between delivery teams and risk-averse stakeholders.

## MIT OpenCourseWare courses

- [15.561 Information Technology Essentials](https://ocw.mit.edu/courses/15-561-information-technology-essentials-spring-2005/): Broad coverage of hardware, operating systems, relational databases and enterprise applications, for people with little background in the technology.

- [6.830 Database Systems](https://ocw.mit.edu/courses/6-830-database-systems-fall-2010/): Relational data modelling, normalisation, and transactions. A configuration management database is still a database, and its integrity problems are data problems.

## Professional development tips

- Work towards a Level 3 service management framework qualification, since it is expected at this role level
- Verify configuration records against the real estate on a schedule, because an unaudited CMDB quietly becomes fiction
- Learn where each configuration item's data actually comes from, and prefer automated discovery to manual entry
- Record change requests fully enough that someone can reconstruct the decision a year later
- Solve the small problems you can independently, and say clearly when something exceeds your remit
- Learn to explain availability, capacity, and continuity concepts plainly, since you will be asked
- Ask to observe the change advisory board, because seeing the decisions made changes how you record them
