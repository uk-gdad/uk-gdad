# UK GDAD PCF assessments (by yourself)

Practice psychometric assessment material for every role level in the United
Kingdom Government Digital and Data (GDAD) Profession Capability Framework
(PCF).

**205 documents**, one per role level, each written from that level's
[role summary](../uk-gdad-pcf-role-summaries).

> **This is practice material, not an assessment instrument.** It is not
> validated, not normed, and not fit for making decisions about people. Every
> document repeats this in its Advisory section.

## Who this is for

Someone preparing for the kind of assessment a role level might use — working
through the same four assessment types alone, at their own pace, reading each
answer after trying the question honestly. Running a hiring panel or
capability review instead? See
[`uk-gdad-pcf-psychometric-assessments-by-assessor`](../uk-gdad-pcf-psychometric-assessments-by-assessor),
which holds the answer key back from the candidate and is written for
whoever is administering it.

## Why job-specific

Employers increasingly use *workplace job-specific* assessments — tied to the
actual skills and duties of a role — rather than generic aptitude tests. These
documents follow that approach: scenarios come from the accountabilities the
framework lists for the level, so the practice is about the job.

## What a document contains

| Section | What it holds |
| --- | --- |
| Introduction | What this is and how to use it |
| Advisory | The standing caution |
| Workplace job-specific cognitive assessment | Inference and problem solving in the role's domain |
| Workplace job-specific numeric reasoning assessment | The numbers this role handles |
| Workplace job-specific verbal reasoning assessment | The documents this role reads |
| Workplace job-specific situational judgement assessment | Scenarios from the role's accountabilities |
| Conclusion | What to do next |

Every practice item comes with a worked answer and an explanation.

Full contract: [spec/index.md](spec/index.md).
